Типы записей

  • ⏳ Задача — важность, сложность (=XP), время, период, повтор, зависимости, навык.
  • ⚡ Действие — запись, перенос, завершение. Множитель опыта — у действия и решения.
  • 🛠 Решение — закрывает проблему; множитель и мысли-помощники; XP = сложность проблемы × множитель.
  • 💭 Мысль — оценка дня.
  • 🙂 Состояние — типовое, с причиной и оценкой настроения.
  • 💛 Желание — типовое, с силой и статусом.

XP

  • Сложность задачи = количество XP.
  • Множитель есть у действия и решения. При завершении итог = сложность задачи × множитель; у решения — сложность проблемы × множитель.
  • Действие без завершения (запись/перенос) может менять ценность задачи своим множителем.

Навыки

  • Корневой узел — карточка дерева (не удаляется, не перемещается).
  • Клик по узлу — карточка обзора с кнопками: редактировать, создать дочерний, удалить, переместить, обзор связей, обзор задач.
  • Категории навыков настраиваются в 🌳 Навыки → 🏷️ Категории.

Модель

  • Узлы копят опыт. Суммарный XP узла = свой + всех потомков.
  • Негативное дерево отнимает опыт.
  • Связи влияния между узлами (входящие/исходящие) — отдельно от иерархии. Показываются в карточке узла и на мини-карте связей.
  • Корневой узел синхронизирован с полями дерева.
Версия 3.7
  • Сделано СИМ с Алисой
  • Новый тип записи «🛠 Решение»: закрывает проблему (переводит её в «решена») и начисляет XP = сложность проблемы × множитель — по образцу связки «задача → действие».
  • У проблемы появились сложность (база XP) и навык; у решения — привязка к проблеме, множитель и мысли-помощники (мысли с привязкой к проблеме).
  • Кнопка «🛠 Решить…» в предпросмотре проблемы открывает форму решения; «↩ Открыта» возвращает проблему в открытые и снимает отметку решения.
  • Мысли можно привязывать к проблеме; в предпросмотре мысли видно, в каком решении она помогла.
  • «⚡ XP за день» учитывает опыт от решений; CSV — колонка closesProblemId; схема базы v11.
